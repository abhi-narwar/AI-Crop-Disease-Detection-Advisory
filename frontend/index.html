        ENGINEERING OVERVIEW

        System Architecture & Methodology

        🧠

        Transfer Learning Architecture

        Employs MobileNetV2 with inverted residual bottlenecks and depthwise separable convolutions pretrained on ImageNet. A custom classification head features GlobalAveragePooling2D, BatchNormalization, and Dropout for robust feature extraction.

        📊

        Rigorous 70:15:15 Split

        A strict stratified 70% train, 15% validation, and 15% testing split is maintained with deterministic seed 42. Duplicate hash filtering and corrupted file removal guarantee zero test set data leakage.

        ⚡

        Modular FastAPI Backend

        High-throughput asynchronous Python FastAPI service with strict MIME type validation, file payload limits, CORS security, structured health checks, and Swagger OpenAPI interactive documentation.
